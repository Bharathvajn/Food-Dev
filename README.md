# 🍔 Food Dev

A modern food ordering and management web application built to provide a seamless experience for users to browse food items, place orders, and manage food-related services.

## 📌 Overview

Food Dev is a full-stack web application that allows users to:

- 🍕 Browse food items
- 🔍 Search and filter dishes
- 🛒 Add items to the cart
- 📦 Place food orders
- 👤 User authentication
- 📱 Responsive design for desktop and mobile devices

## ✨ Features

- User Registration & Login
- Food Menu Display
- Category-wise Food Listing
- Search Functionality
- Shopping Cart
- Order Management
- Responsive UI
- Secure Authentication

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/bharathvaj-n/food-dev.git
```

### Navigate to the project folder

```bash
cd food-dev
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm start
```

or

```bash
npm run dev
```
